# Amazon India Sales & Performance Dashboard

## 📊 Project Overview

This project presents an interactive Amazon India Sales & Performance Dashboard created using Microsoft Excel.

The dashboard provides a clear overview of sales, profit, orders, products, order status, payment methods, fulfillment methods, and geographic performance.

## 📌 Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Total Units Sold
- Average Order Value
- Profit Margin %
- Return Rate %
- Cancellation Rate %
- Monthly Sales & Profit Trend
- Category-wise Sales, Profit & Units Sold
- Top 10 Products by Sales
- Order Status Distribution
- Category-wise Returns & Cancellations
- Sales & Profit by Payment Method
- Sales & Profit by Fulfillment Method
- State-wise Sales, Profit & Orders

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Dashboard Visualization

## 📁 Project File

The Excel dashboard file is included in this repository.

## 🎯 Objective

To analyze Amazon India sales data and present key business insights through an easy-to-understand interactive dashboard.
